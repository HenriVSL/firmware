# v0.3.0: first image on the radio

The first DeltaMM image: start-up, power hold, LEDs, power knob and
watchdog. It never drives the transmitter, audio, display or radio chips.

## Before you start

- A verified full backup of this radio, made with factory firmware still on
  it (`docs/hw-tests/v0.2.0.md`).
- The factory V3.06 `.CDD`, `.spi` and `.CDI` files, to flash back at the end.
- A way to send update files in update mode: the vendor update tool, or
  another tool that speaks its protocol.
- Battery charged. Remove the battery if anything below gets stuck.

## Build the update files

```sh
cmake --build --preset host
cmake --preset fw-d878uv2-release \
    -DDMM_STOCK_FIRMWARE=/path/to/D878UVII_V3.06.CDD \
    -DDMM_RADIO_TOOL=$PWD/build/host/tools/dmm_radio/dmm-radio
cmake --build --preset fw-d878uv2-release --target update-files
```

The files land in `build/fw-d878uv2-release/boards/anytone_d878uv2/package/`
as `DeltaMM_0.3.0.CDD`, `.spi` and `.CDI`.

## Steps

| # | Do | Expect |
| --- | --- | --- |
| 1 | Build the update files as above | `Backup: ... (verified)`, image about 10 KB |
| 2 | `dmm-radio prepare build/fw-d878uv2-release/boards/anytone_d878uv2/deltamm.bin <factory firmware .CDD> <folder> --dir <empty folder>` | Refused: no backups found |
| 3 | Power on holding PF1 + PTT, send the DeltaMM files | Transfer completes |
| 4 | Power off | The image is already written; no second PF1 + PTT start is needed |
| 5 | Power on normally | Red LED for about 0.3 s, then green for 0.1 s once a second. Display dark, no sound |
| 6 | Press PTT and a few keys | Nothing happens; no transmission on a nearby receiver |
| 7 | Leave it on for 5 minutes | The green blink stays regular, with no red flash (a red flash means it restarted) |
| 8 | Turn the power knob off | LEDs stop at once and the radio is off |
| 9 | Turn it on again | Same as step 5 |
| 10 | Power on holding PF1 + PTT, send the factory V3.06 files, then power off and on normally | Factory firmware starts as before |
| 11 | Read the radio with qdmr or the CPS; check a few channels | Codeplug and settings unchanged |

## If something is off

- Red flash, then nothing: the power knob reads the wrong way round. Note it
  and turn the knob off.
- No light at all: the image did not start. Go to step 10.
- Still on after the knob is off: power hold works the other way round.
  Remove the battery, then go to step 10.

## Report back

- Which steps passed, and anything that looked different.
- How long the red flash and the green blinks look, roughly.
