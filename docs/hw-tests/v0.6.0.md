# v0.6.0: display and backlight

The display shows a test pattern for 3 s after start, then the log. The
panel is set up with the controller's power-on defaults.

## Before you start

- v0.5.0 passed on this radio.
- A terminal on the log port as in v0.4.0.

## Steps

| # | Do | Expect |
| --- | --- | --- |
| 1 | Flash and power on | Backlight on; colour bars white, yellow, cyan, green, magenta, red, blue, black from left to right; white frame; `TL` `TR` `BL` `BR` in the matching corners; "DeltaMM" in large letters |
| 2 | Check the text lines | `8x16 äöå ÄÖÅ`, `6x12 Hyvää päivää!`, `5x8 The quick brown fox`, all readable |
| 3 | Wait 3 s | Log view: header `DeltaMM 0.6.0  up N s` counting, log lines below, including `display: panel strap 0` or `1` |
| 4 | On the log port: `light 1` ... `light 5` | Display and keypad get brighter step by step; `light 0` turns the light off |
| 5 | `pattern`, then `logview` | Test pattern again, then back to the log |
| 6 | `panel off`, then `panel on` | Screen goes plain white (the panel lets all light through while off), then the picture returns |
| 7 | Press keys | Nothing breaks; keys do nothing yet |
| 8 | Leave it on 5 minutes | Header keeps counting, no restart |
| 9 | Flash factory V3.06 back | The factory firmware's display works as before |

## If something is off

- Picture mirrored or upside down: report which corner `TL` is in.
- Red and blue swapped (bars read white, cyan, yellow, ...): report it.
- Brightness goes down as the level goes up: report the strap value.

## Report back

- The `panel strap` value, and photos of steps 1 and 3 if anything looks off.
