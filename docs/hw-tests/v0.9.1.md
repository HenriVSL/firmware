# v0.9.1: fixes from the first hardware run

Fixes the bugs found while testing v0.6.0 to v0.9.0. Only the changed
parts need checking; nothing new is added. Still read-only: nothing is
ever written to the data flash.

- Backlight: lit while the pin is high, with levels per panel variant.
- Channel knob: clockwise counts up.
- Calibration pages the flash flags as uncorrectable are used.
- A short wait before power is released, so the last log line gets out.
- Console: CR LF counts as one Enter.
- `dmm-radio ports` lists DeltaMM's ports; update files carry the image's
  version.

## Before you start

- v0.9.0 ran on this radio, and the verified full backup from v0.2.0 is
  still in the backup folder.
- `dmm-radio` from this version's host build.

## Steps

| # | Do | Expect |
| --- | --- | --- |
| 1 | `ls` the update files | Named `DeltaMM_0.9.1.*` |
| 2 | Flash and power on normally | Screen lit at start-up without any console command |
| 3 | `light 0` to `light 5` on the log port, a few seconds each | 0 dark, then each level brighter than the one before |
| 4 | Turn the channel knob clockwise, then back | Clockwise counts up, one per click |
| 5 | `dmm-radio ports` | The two DeltaMM ports, marked `(DeltaMM)` |
| 6 | Start-up log line, then `battery` on the log port | `calibration: copy A, battery offset ... mV (flash check failed, ...)`; the `battery:` line without `(uncalibrated)` |
| 7 | Compare the header voltage with a meter, if there is one | Within about 0.05 V |
| 8 | `dmm-radio check-backup` | `Note:` lines for the flagged areas, each part `identical`, then `Result: the radio's data matches the backup` |
| 9 | Type a command in a terminal that sends CR LF | Runs once, no second empty prompt |
| 10 | `autooff 1`, wait a minute | `Switching off`, then the screen goes dark (not white) |
| 11 | Turn the knob off with the log port open | `power switch off` reaches the PC before the port goes |
| 12 | Flash factory V3.06 back; read with the CPS or qdmr | Codeplug and settings as before, nothing lost |

## If something is off

- Screen dark at step 2: send `light 5`. If that lights it, the level
  table is wrong for this panel; report which levels light it.
- Step 11 line still missing: the knob most likely cuts the battery
  directly. Report it; nothing to fix in that case.
- `check-backup` shows `DIFFERENT`: report which parts and the first
  address. Do not flash anything else until it is understood.
