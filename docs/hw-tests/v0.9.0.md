# v0.9.0: reading the data flash

DeltaMM now reads the radio's data flash (codeplug, calibration),
following its table of replaced blocks. Nothing
is ever written: the flash driver has no write or erase operation. The
battery reading now uses the radio's own calibration, so an empty battery
switches the radio off (dark, until the knob is turned off).

The radio now has two USB serial ports: **DeltaMM data** (first,
`/dev/ttyACM0` on Linux) for `dmm-radio`, and **DeltaMM log** (second,
`/dev/ttyACM1`).

## Before you start

- v0.8.0 passed on this radio, and the verified full backup from v0.2.0 is
  still in the backup folder.
- `dmm-radio` from this version's host build.

## Steps

| # | Do | Expect |
| --- | --- | --- |
| 1 | Flash and power on, open the log port | `storage: flash 98 cb, 256 MB, ...` and `calibration: copy A, battery offset ... mV` |
| 2 | Type `storage` on the log port | The same chip id and remapped-block count |
| 3 | `peek 2F60000` | 16 bytes, `(ok)`; byte 0x14 and 0x15 of the calibration read `77 77` (at `peek 2F60010`, the 5th and 6th bytes) |
| 4 | `dmm-radio info` | `DeltaMM: 0.9.0`, storage id and size |
| 5 | `dmm-radio check-backup` | Each backup part `identical`, then `Result: the radio's data matches the backup` |
| 6 | Compare the header voltage with a meter | Within about 0.05 V (v0.8.0 was off by the offset) |
| 7 | `dmm-radio dump 0x0 0x100000 first-mb.bin` | About 1 MB written, no `Problem:` lines |
| 8 | Run step 7 again to `first-mb-2.bin` | Same SHA-256 both times |
| 9 | Flash factory V3.06 back; read with the CPS or qdmr | Codeplug and settings as before, nothing lost |

## If something is off

- `no data flash found (id xx yy)`: report the id. The radio still runs;
  only storage features are off.
- `check-backup` shows `DIFFERENT`: report which parts and the first
  address. Do not flash anything else until it is understood.
- `could not be read correctly` lines: report the addresses.

## Report back

- The `storage:` and `calibration:` lines from step 1.
- The `check-backup` output.
- How long step 7 took.
