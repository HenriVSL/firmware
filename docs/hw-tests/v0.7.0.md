# v0.7.0: keys and knobs

After the test pattern the display shows the key test: every key as a box
that turns green while pressed, the channel knob count and the volume.
Holding Exit for a second switches between the key test and the log. Keys
only light boxes; PTT does nothing else.

This image turns the debug port off so PF2 works (PF2 shares a pin with
it). Build with `-DDMM_KEEP_SWD=ON` to keep SWD instead.

## Before you start

- v0.6.0 passed on this radio.
- A terminal on the log port, to see `input:` lines.

## Steps

| # | Do | Expect |
| --- | --- | --- |
| 1 | Flash and power on | Test pattern, then the key test screen |
| 2 | Press each digit, `*`, `#`, Menu, Exit, Up, Down, P1, P2 in turn | Only that key's box turns green; log `key <name> pressed` / `released` |
| 3 | Press PF1, PF2, PF3 and PTT in turn | Their boxes; note if PF1 and PF2 come out swapped |
| 4 | Hold PF3 and press 1, Menu, P1 | All held keys show; P1 may not show while PF3 is down (they share a line) |
| 5 | Hold PTT and press 5 | Both show |
| 6 | Hold Up for 2 s | One `pressed`, then `held` after 1 s |
| 7 | Turn the channel knob one click clockwise, then one back | `Knob 1`, then `Knob 0`; log `knob +1` / `knob -1` |
| 8 | Turn it fast through 10 clicks | Count changes by 10, no jumps back |
| 9 | Turn the volume knob from end to end | Volume goes from near 0 % to near 100 %, and changes smoothly |
| 10 | Hold Exit 1 s, then again | Log view, then key test |
| 11 | Check the display while pressing keys fast | No garbage on the screen |
| 12 | Flash factory V3.06 back | The factory firmware works, all keys too |

## If something is off

- A key lights a different box: report which key and which box.
- Knob counts 2 per click, or every other click: report it (the counts per
  click is a board setting).
- Knob counts the wrong way: report it.
- Volume runs backwards: report it.

## Report back

- Any key or knob that does not match, and the knob counts for step 7.
