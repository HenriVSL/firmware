# v0.4.0: log over USB

Adds a USB serial port that carries the radio's log. Everything from
v0.3.0 still applies; the radio still never transmits.

## Before you start

- v0.3.0 passed on this radio.
- A terminal program for serial ports: `picocom` or `screen` on Linux and
  macOS, PuTTY or Windows Terminal with a COM port on Windows. Any speed
  setting works.
- Linux: if ModemManager is installed, it may open the new port for a few
  seconds after it appears. Wait, or stop ModemManager while testing.

## Steps

| # | Do | Expect |
| --- | --- | --- |
| 1 | Build and flash as in v0.3.0 | Red flash, then the green heartbeat |
| 2 | Connect the programming cable | A new port appears: `/dev/ttyACM0` (Linux), a COM port (Windows). `lsusb` shows `1209:0001 DeltaMM AnyTone D878UVII` |
| 3 | Wait 30 s, then open the port, for example `picocom /dev/ttyACM0` | The boot lines appear at once: `DeltaMM 0.4.0 on anytone_d878uv2`, the clock line, then uptime lines |
| 4 | Watch for a minute | An uptime line every 10 s with unused stack words for `system` and `link`, both above 50 |
| 5 | Close the terminal, wait 20 s, open it again | Logging resumes; the lines from while it was closed arrive first |
| 6 | Unplug the cable, wait, plug it in again, open the port | The port comes back and the uptime lines continue, counting from the first boot |
| 7 | Type into the terminal | Nothing happens; the radio ignores input |
| 8 | Leave the port open for 10 minutes | Lines keep coming; no restart (the uptime keeps rising) |
| 9 | Turn the power knob off with the cable connected | The log shows `power switch off` and the radio goes off. If it stays on, note it: something else powers it, and it should restart once the knob is turned back on |
| 10 | Flash factory V3.06 back as in v0.3.0 | The factory firmware works, CPS reads the radio |

## Report back

- Which steps passed.
- The clock line from step 3 (crystal or internal oscillator).
- The unused stack numbers from step 4.
- Anything odd with the port: it not appearing, errors in `dmesg`, or the
  log stopping.
