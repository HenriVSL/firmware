# v0.2.0: back up a radio running factory firmware

Read-only. Nothing is written to the radio; it restarts at the end of each
session, as after any CPS read.

## Before you start

- AnyTone D878UVII on factory firmware, programming cable, battery charged.
- Close the AnyTone CPS, qdmr and anything else using the radio's port.
- Linux: your user is in the group that owns the port (often `dialout`).
- Build `dmm-radio` with the host preset (needs Qt 6.8 with Qt Serial Port).

## Steps

| # | Do | Expect |
| --- | --- | --- |
| 1 | Switch the radio on, plug in the cable, run `dmm-radio ports` | One port listed (`/dev/ttyACM0`, `COM5`, ...) |
| 2 | `dmm-radio backup --quick` | Radio shows PC READ, then restarts. Output ends with `Verified: yes (quick backup...)` in a few seconds |
| 3 | Run step 2 again | Second folder; `calibration` and `radio-info` hashes in both `manifest.json` files are identical |
| 4 | `dmm-radio backup` | Progress for the system area, about 2–5 minutes, `Verified: yes` |
| 5 | `dmm-radio list` | Three backups, all `verified` |
| 6 | `dmm-radio verify <folder from step 4>` | `Verified: yes` |
| 7 | Use the radio normally, then read it once with qdmr or the CPS | Radio and programming work as before |

## Report back

- The time step 4 took.
- Any `Warning:` or `Problem:` lines.
- Whether the radio needed a manual restart after any step.

Don't share the backup files themselves: they hold the radio's serial
number and its factory calibration. The default location is the user data
folder (`~/.local/share/deltamm/backups` on Linux).

## Undo

Nothing to undo.
